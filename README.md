# Resume AI

An AI-powered resume analysis platform built with Python.

## Features

* Resume parsing
* Resume evaluation
* Automated analysis workflows
* GitHub-based project management

## Tech Stack

* Python
* Git
* GitHub

## Installation

```bash
git clone https://github.com/udaykumar7469/resume-ai.git
cd resume-ai
pip install -r requirements.txt
```
